# AgendaPro - Proyecto Integral Full Stack

## Descripción
Aplicación web completa de gestión de actividades desarrollada como proyecto integral. Combina autenticación de usuarios con base de datos relacional y operaciones CRUD sobre una base de datos NoSQL.

## Tecnologías Utilizadas
* **Frontend:** HTML5 Semántico, CSS3, Jinja2
* **Backend:** Python 3, Flask
* **Base de Datos Relacional:** SQLite3 (Registro y autenticación de usuarios)
* **Base de Datos NoSQL:** MongoDB (Operaciones CRUD de actividades)

## Instrucciones de Ejecución
1. Abrir la carpeta del proyecto en Visual Studio Code.
2. Activar el entorno virtual: `.venv\Scripts\activate`
3. Instalar dependencias: `pip install -r requirements.txt`
4. Verificar que el servicio de MongoDB esté activo.
5. Ejecutar `python app.py` y abrir `http://127.0.0.1:5000` en el navegador.
